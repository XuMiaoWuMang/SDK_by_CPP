# 使用文档

## 1. 项目介绍

AI_SDK_CPP 是一个基于 C++ 的 SDK，用于调用 AI 模型服务。
- 可接入云端的deepseek模型
- 可接入本地的ollama模型
- ⽀持多轮聊天，全量消息和流式消息
- 支持数据持久化，包括会话记录、消息记录等

## 3. 使用方法

### 3.1 ChatSDK 方法说明

ChatSDK 是整个 SDK 的对外统一入口，通过 `chat_sdk::ChatSDK` 类调用。方法如下：

| 方法 | 功能 | 参数 | 返回值 |
| --- | --- | --- | --- |
| `initLLMManager` | 初始化模型管理器（注册并初始化所有模型） | `configMap`：模型配置列表 | `bool`：是否初始化成功 |
| `createSession` | 创建会话 | `modelName`：模型名称 | `std::string`：会话 ID，失败为空串 |
| `deleteSession` | 删除会话 | `sessionId`：会话 ID | `bool`：是否删除成功 |
| `getSessionList` | 获取所有会话 ID 列表 | 无 | `std::vector<std::string>` |
| `getSession` | 获取指定会话信息（含消息记录） | `sessionId`：会话 ID | `std::shared_ptr<SessionInfo>`，失败为 `nullptr` |
| `getModelList` | 获取可用模型列表 | 无 | `std::vector<std::string>` |
| `sendMessage` | 发送消息，全量返回 | `sessionId`、`message`（用户消息内容） | `std::string`：模型回复内容，失败为空串 |
| `sendMessageStream` | 发送消息，流式返回 | `sessionId`、`message`、`callback`（回调函数） | `std::string`：完整回复内容 |

### 3.2 配置说明

- `RemoteConfig`：云端模型配置，需设置 `_modelName` 和 `_apiKey`（如 DeepSeek）。
- `OllamaConfig`：本地 Ollama 模型配置，需设置 `_modelName`、`_endpoint`（如 `http://127.0.0.1:11434`）和 `_modelDesc`。
- 两者均继承自 `Config`，可配置 `_temperature`（默认 0.7）和 `_maxTokens`（默认 2048）。

### 3.3 使用示例

```cpp
#include <ai_cpp_sdk/ChatSDK.hpp>
#include <ai_cpp_sdk/util/logger.hpp>
#include <memory>

// 1. 创建 SDK 实例
auto sdk = std::make_shared<chat_sdk::ChatSDK>();

// 2. 配置模型
// 云端 DeepSeek 模型
auto deepseekConfig = std::make_shared<chat_sdk::RemoteConfig>();
deepseekConfig->_apiKey = std::getenv("DEEPSEEK_API_KEY");
deepseekConfig->_modelName = "deepseek-v4-flash";

// 本地 Ollama 模型
auto ollamaConfig = std::make_shared<chat_sdk::OllamaConfig>();
ollamaConfig->_modelName = "deepseek-r1:1.5b";
ollamaConfig->_endpoint = "http://127.0.0.1:11434";

std::vector<std::shared_ptr<chat_sdk::Config>> configLists = {
    deepseekConfig, ollamaConfig};

// 3. 初始化模型管理器
sdk->initLLMManager(configLists);

// 4. 获取可用模型列表
std::vector<std::string> modelList = sdk->getModelList();

// 5. 创建会话
std::string sessionId = sdk->createSession("deepseek-v4-flash");

// 6. 发送消息 - 全量返回
std::string response = sdk->sendMessage(sessionId, "你好,你是谁?");

// 7. 发送消息 - 流式返回
auto callback = [](const std::string &content, bool streamFinished) {
    std::cout << content << std::endl;
};
std::string fullResponse =
    sdk->sendMessageStream(sessionId, "你好,你是谁?", callback);

// 8. 获取会话列表 / 指定会话信息 / 删除会话
auto sessionList = sdk->getSessionList();
auto sessionInfo = sdk->getSession(sessionId);
sdk->deleteSession(sessionId);

```

## 4. 温馨提示

- 确保在使用前配置好环境变量，如 `DEEPSEEK_API_KEY`、`GEMINI_API_KEY`、`CHATGPT_API_KEY`。
- 确保在使用前配置好 Ollama 模型的 `endpoint`。
- 本项目虽写了ChatGPT模型和Gemini模型，但并未进行测试，如需使用，请先微调数据的读取和校验逻辑(主要是 `sendMessageStream` 方法和 `sendMessage` 方法)。
